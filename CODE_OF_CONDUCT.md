# Code of conduct

Be respectful, specific and constructive. Discuss ideas and code without harassment, discrimination, threats, personal attacks or disclosure of another person's private information. Welcome newcomers, explain feedback clearly and respect authors' rights to their manuscripts.

Maintainers may remove abusive contributions, close disruptive discussions or restrict participation. Decisions should reflect the behavior and its effect on the community.

Report concerns through an available repository moderation or GitHub reporting channel. Do not publish private personal details in an issue. The project does not currently advertise a private contact address or guarantee a response time.
