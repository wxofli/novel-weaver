# 新作品自动创作约定验证

变更范围：`book_init` 原有 AGENTS.md 追加机制不变，扩充其内置正文为协议、人称与六条压缩创作底线；同步入口和说明。工具请求字段、采纳事务与数据库结构不变。只作用于使用新版源码新建的作品，不安装用户插件，不迁移既有作品。

## 内容走查

实际阅读：本仓库开发约定、作品约定模板、初始化器、novel 入口及 craft-examples.md 的 C01–C12，并补充合成 C13。以下为知道说明后的自审，不是盲评或独立审查。

- C01–C04：重复工序可概述，风险变化、人物选择与安静场景的情绪推进应保留；压缩规则不强制快节奏。
- C05–C09：角色误判不等于事实矛盾；伏笔修订不能提前泄底，数据库欠账不自动变成剧情义务。
- C10–C12：保留阅读范围、版本、人称例外和条件授权；不把保存审查等同于完成独审。
- C13：删掉让票后的重复升华；保留三年不坐船的有效概述，不补造原因或身体反应。

局限：这是有限合成样例的规则走查，没有运行模型生成对照、真实连载读者试验或全书质量验证。测试只验证自动生成、作者文本保留、重复调用不追加、旧作品不迁移及文档发布完整性。
