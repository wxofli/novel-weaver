## 合成案例手工走查

材料：[12组正反例](../skills/novel/references/craft-examples.md)。本轮检查者同时编写规则和样例，以下是已知预期答案的自审走查，不是盲评、独立模型测试或真实作品终审。每组只判断给出的片段，不外推全书。

| 案例 | 具体判断与最小处理 | 必须保留的边界 / 复核点 |
| --- | --- | --- |
| C01 | 第二次四步操作没有新作用，可概述；成本低 | 裂桌脚引发赔偿决定，应保留危险、决定及代价；相同动词不等于重复场景 |
| C02 | 扫地三次确认可并为行动；成本低 | “他亲口说过？”引出不烧遗书的选择，删除会破坏冲突 |
| C03 | 连续念余额可压缩；多场调整成本中 | 药钱与还债冲突、债务归属须保留；按台账复核钱款，不能靠正文重复维持正确 |
| C04 | 重复等船感受需检查是否能合并；成本低 | 衣扣、退票与寄钱推进关系和决定，不能因安静判无效，也不强添追杀 |
| C05 | 钥匙毁坏与完好开门需联查第2、8章；成本中，若影响唯一解则重新评估 | “他以为”限定认知，后文邻居送药不自动构成设定冲突 |
| C06 | 在前段可见处补红漆感知，后段保留关联证据；至少两处联动，成本中 | 不让侦探仅凭前段颜色定罪；先检视题材、视角是否允许有意延迟，不能一律判作弊 |
| C07 | 第20、21—25章重分配告别与归宿信息；成本中，核心重开无因果才升级 | 夺冠获得找姐姐的船票是阶段回报，应保留；不能把每次胜利当终章 |
| C08 | 姐姐不回、主角接受并归乡已回答关系选择；可支持完成方向，仍须阅读全文 | 箱中声音仅是新线索，需补读身份与回应；确认材料齐全后再判返修，不能只凭开放标签放行 |
| C09 | 当场还碗而记忆陈旧，处理同步；正文修改成本为零 | 药方救人的承诺需追踪，列已查范围才能认定未兑现；不为清库再写一次还碗 |
| C10 | 第1、12、30章只能给阶段结论；先补读，不估删改成本 | 结局A/B分开，B的团圆不能作为A的完成证据 |
| C11 | 三类人物一律审查腔，按身份与压力调整；多场成本中 | 船工抓绳和官员追问都有实际功能，不能全删谨慎表达 |
| C12 | 突兀叙述“我”需修，成本低；“我留下”的对白不改 | 自审不满足另一执行者审查条件，保存 review 也不等于通过；满足既有授权后无需再询问 |

走查发现并修正了正文闭环中的旧表述冲突：原“未明确采纳就停止”可能忽略既有条件授权。现将入口、写作 Skill 和公共协议统一为核实适用授权及其条件，保留精确版本和记忆流程。这是文档规则修正，后端尚不验证独立审查身份。

## 后续行为验证方法与局限

本轮不在主线程作品上试写，不派发独立审查代理，也不触发采纳。未验证新规则能在真实长篇持续改善节奏；发布前可在另建的合成测试项目中进行以下验证：

1. 隐去样例答案，给另一会话提供变体材料，先要求标出已读范围、证据、影响和最小修法；再比对保留边界，记录漏报与误报，不用总分替代解释。
2. 提供连续章段，要求压缩工序但保留最终决定与最后一幕；人工对比前后因果、知情、资源与声音，检查是否把删去的说明又补回。
3. 给只有中间几章的材料及两个互斥结局，检查能否暂缓全书判定、分开结局证据；给正式全文后再检查主线与余波。
4. 在隔离宿主中验证新增 Skill 实际发现；源码路由和 ZIP 检查不能替代安装后的宿主验证。

后端能力需求单独见[未实现方案](editorial-backend-roadmap.md)。
