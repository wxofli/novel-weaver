# 跨文化小说改编工作流

这是本类任务的顶层编排入口，不依赖额外安装 `foreign-novel-localizer`。按用户要求选择和串联下列 Skill；直接读取相关文件并执行其中的工作，不假设存在独立调度程序或自动派发子 agent。按需读取，跳过用户没有要求且不是完成目标所必需的环节。

默认以中文交付；未指定目标时，可以暂用中国大陆中文网文作为工作假设并标明。若用户希望反向借鉴“中文网文出海”的做法，流程是海外选书 → 来源与权利核对 → 语言理解与拆书 → 中文文化迁移 → 规划、试写和审校。不可把视频中的出海平台或收益推断为中文市场结论。

## 入口与权利状态

收集用户已有的原文标题、作者、链接／本地文件或梗概，以及目标语境、类型、篇幅、交付范围和希望保留的特点。只问会影响下一步的关键缺项。仅有书名时先核实同名、版本、作者与可读范围；没有原作时先按题材找候选作品。不能把简介或评论当成已读正文。

记录素材是用户自有、已有许可、适用地区的公版／其他适用例外，还是待核实。用户说有权时记录其陈述，不假称已审阅合同。准备公开或商业使用时，提醒核对原作及译本、语言、地域、媒介、期限、署名等范围；免费可读、购买或改名不等于有改编权。未知权利时继续可做的选材、分析和方案，同时标明待核项，不声称已获授权。

给用户的需求选择路线：**有权改编**可在授权范围内对应原作场景、人物和情节；**题材启发／独立原创**提炼一般叙事功能，另行设计人物、事件因果、结局和语言，不按原作独特情节组合逐章换皮。相似率、改名或 AI 检测都不能保证合法。

## 按阶段组合 Skill

| 阶段和交接内容 | 按需读取并执行 | 产物与下一步 |
| --- | --- | --- |
| 选书、来源、语言与目标文化资料 | [novel-research](../novel-research/SKILL.md) | 作品身份、可读范围、资料链接、事实和未知项；交给拆书与迁移。优先原平台，研究模板和入口见 [references/research.md](references/research.md)。 |
| 方向与故事驱动力 | [novel-idea](../novel-idea/SKILL.md) | 提炼阅读体验、主角欲望、阻力和可持续冲突；根据选定路线区分原作表达和通用机制。没有用户要求时不自动建书。 |
| 拆解、人物与文化迁移、世界和大纲 | [novel-plan](../novel-plan/SKILL.md) | 按 [references/workflow.md](references/workflow.md) 记录来源位置、情节因果及人物、称谓、机构、制度、场景映射。生成目标故事规则、角色关系和用户要求尺度的大纲；标清事实、候选和作者决定。 |
| 用户要求试写、写章或修订 | [novel-write](../novel-write/SKILL.md) | 使用已定约束与本书上下文；聊天中试写或在作品中保存候选稿。默认第三人称，除非作者指定其他人称。用户请求的长篇工作可继续，不将样章变成一律停下的审批。 |
| 用户要求审稿，或正文闭环需要审查 | [novel-review](../novel-review/SKILL.md) | 引用具体稿件检查因果、人物动机、知识边界、译名／称呼、时间线与伏笔；必要时对照来源和迁移表报告具体相似之处，不把任何分数当作侵权结论。 |
| 已有作品的状态或待恢复记忆 | [novel-memory](../novel-memory/SKILL.md) | 查询已发生事实、角色知情和同步状态；正文采纳后有同步任务就依协议恢复。 |

每次交接携带与下一阶段有关的原作身份、已读范围、权利状态、用户创作约束、已选决定、证据来源、当前产物及未决项。用户已明确要求多个阶段时顺序执行，缺材料时先完成不依赖缺项的部分；不要在每一阶段重复要求确认。模型自己做跨文化映射和叙事判断，Novel Weaver 后端只负责其已有的数据与事务能力。

用户明确要求合用其他已安装的 Skill，或其能力对当前步骤有明显帮助时，可以按各自说明按需组合；不存在则说明并用本插件能力继续。避免把外部工具或教程当成已安装服务，也不要调用 `foreign-novel-localizer` 再反向路由回本 skill。所有组合仍受下列作品与采纳边界约束。

## 与作品和正史的边界

- 普通选书、讨论、方案或聊天试写不自动建书或持久化。只有作者明确要求创建作品项目时，按 [novel](../novel/SKILL.md) 和[公共协议](../novel/references/workflow.md#调用与身份)初始化；缺少标题或目录时只问缺项。已有作品先绑定真实 `project` 和 `book_id` 并检查状态，不能把另一部书当目标。
- 作者要求把来源调查和拆解保存到已有项目时，按 `novel-research` 将带出处的摘要存为 `research` 参考；不要未经要求复制完整原作。目标书未来大纲、风格和已选设定分别按 `novel-plan` 保存与采纳，研究、大纲与未选方案不能冒充已发生的情节。
- 参考原作不是目标书的已采纳正文，不能为了拆书调用 `novel-import` 把它导入正史。只有用户明确要求将自己的既有稿件作为目标作品正文导入时，才使用 [novel-import](../novel-import/SKILL.md) 的预览、确认与同步流程。
- 作品中的正文新版本交 `novel-write` 完成上下文、候选稿、候选记忆及审查；作者明确采纳该具体版本后才提交正文与记忆。素材、计划、已采纳正文和角色知情不得互相混淆。报告实际版本、待采纳状态及同步／索引待办，不暗示全部已完成。
