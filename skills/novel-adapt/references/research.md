# 调研记录与可复用来源

调查日期：2026-11-12。以下内容是当日能访问的信息，不代表项目已运行验证、作品已获授权或后续网页内容不变。再次使用具体来源时应核对可用性、版本和现行规则。

## 可借鉴的 GitHub 项目

1. [aimerfeng/novel-to-webnovel：SKILL.md](https://github.com/aimerfeng/novel-to-webnovel/blob/main/SKILL.md)：面向日轻或机翻稿的网文化，描述格式整理、风格规范、样例、分块及质检。强项是语言与流程，不能自动完成原作权利核验或文化制度重构。其自动化是作者描述，本次未安装执行。
2. [leenbj/novel-creator-skill：adaptation-workflow](https://github.com/leenbj/novel-creator-skill/blob/main/references/adaptation-workflow.md)：提出查询、拆书、替换角色／背景、改大纲和知识库的链路；该文自己标注“部分实现”，联网查询、引导式改编及知识图谱的完整链路尚待补全。不能把规划说成现成自动功能。
3. [hollis-openlab/ai-novel-rewriter：中文说明](https://github.com/hollis-openlab/ai-novel-rewriter/blob/dev/README_zh.md)：项目说明宣称支持导入分章、场景分析、逐段改写、滚动上下文和审校。它是独立软件，需要环境及模型配置；没有在本次调查中运行。
4. [XTmingyue/harnessNovel](https://github.com/XTmingyue/harnessNovel)：项目说明将拆书、叙事模式抽象和新世界路线设计连起来；其说明还写明故事情节审计暂时关闭。所谓降低相似风险是项目的设计目标，不能当法律保证。本次没有安装运行。
5. [acttk/novel-analyzer](https://github.com/acttk/novel-analyzer)：说明展示章节拆分、逐章分析、运行笔记和全书总结。只把它作为拆书流程参考，未检验效果。

## YouTube：出海教程与反向借鉴

只核对了以下视频的公开搜索结果、标题及简介，没有逐帧观看或核验实际效果。没有发现已核实的“日韩小说改成中文网文”的完整视频教程，不应将相反方向的视频冒充直接案例。

1. [吾爱分享：搬运国内小说到国外平台](https://www.youtube.com/watch?v=cAeqq8_T7tA)：简介声称将中文小说借助 ChatGPT 二次创作并发布到海外，分项目介绍、准备和实操。它是“中→外”方向；收入数字是发布者宣传，未证实，也未证明有版权许可。
2. [饭桶日常：中文网文翻译为英语并尝试发布](https://www.youtube.com/watch?v=o6jXhzWUb0U)：标题描述对中译英和海外发布的尝试，简介仅介绍试验意图，不证明结果和合法性。
3. [Midnight Librarian：AI 拆书与批量改写工具](https://www.youtube.com/watch?v=yrfe3zyE8ug)：简介列出清理分段、导入、提示词配置、改写导出、进度管理；这是通用文案／小说操作演示，并非日韩迁移案例。视频作者的“深度加工”表述不等于取得改编权。
4. [shang peng：AI 小说拆文、设定追踪与续写](https://www.youtube.com/watch?v=sccvLkYAj60)：简介列出拆解、大纲、角色伏笔追踪、续写和精修，属于作者介绍的通用工具流程，本次没有运行其软件。

可以借其环节倒推：原作所在平台选材 → 阅读和核对权利 → 日语／韩语理解或译文辅助 → 拆解叙事 → 中文文化、人物和世界迁移 → 试写审校 → 在授权范围内准备目标平台使用。跨文化改编的制度、关系和剧情因果不是把翻译方向倒过来就自动解决。

## 社区和实际本地化案例

1. [知乎：锻炼写小说拆书这要怎么拆？](https://www.zhihu.com/tardis/bd/ans/2310295311)：回答用一本武侠小说说明主辅线、人物、开篇、铺垫和高潮的拆解。它是经验贴，内容不专门针对日韩网文；后半部分包含课程推广。
2. [新京报：《回廊亭》导演访谈](https://m.bjnews.com.cn/detail/1679033278169921.html)：导演谈日本小说改为中国电影时，调整建筑场景、家庭关系和主角身份。这是小说到电影的跨媒介案例，用于启发文化迁移，不能证明小说改写权限。
3. [中国作家网：韩国学者崔宰溶访谈](https://www.chinawriter.com.cn/n1/2024/0529/c404024-40245835.html)：受访者描述中国网文韩译中对国家细节的调整，并讨论过度本地化。属于中译韩方向、受访者的观察，不代表每个译本或权利状态都已核验。
4. [日本小说家深山铃：转载与翻译说明](https://mypage.syosetu.com/mypageblog/view/userid/1028232/blogkey/3135079/)：作者明确拒绝未经其指定渠道的翻译和转载，说明应该逐作核对权利人意见；不能推广成全站作者的统一授权条款。
5. **小红书核查限制：** 公开搜索未找到能直接核实的“将日韩小说搬回中文并置换人物、世界观”的完整教程原帖，Tabbit 站内会话不可用。因此不把相关二手报道、广告或平台泛内容改写指南冒充这一类教程。可供线索参考的[澎湃报道](https://m.thepaper.cn/newsDetail_forward_31118391?commTag=true)涉及作者称在小红书发现换名后相似的短剧；它是采访报道，不是核验过的教程，也非对该具体争议的司法结论。

## 权利与规则依据

- [国家版权局：《中华人民共和国著作权法》](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)：第十条列明改编权、翻译权等，第十三条涉及改编和翻译作品与原作权利的关系。外国作品是否受保护和保护期限，还要依具体作品、地域及适用规定判断。
- [日本作者的翻译声明](https://mypage.syosetu.com/mypageblog/view/userid/1028232/blogkey/3135079/)是具体权利线索示例，不替代合同。
- [小红书交易笔记模板化洗稿细则](https://school.xiaohongshu.com/rule/detail/3600)针对交易笔记，不能推断其直接适用于所有小说发布；它说明平台可能对形式性改写有单独管理。
- [番茄小说原创作者版权维权指引](https://fanqienovel.com/writer/zone/article/7643774775965253694)提到未经授权改编、抄袭或洗稿的举报途径。平台规则可能变化，发布前应查看目标平台现行条款。

没有统一的“换多少设定／多少字就安全”公式；是否构成侵权须结合表达、使用方式、许可、例外和适用法律具体判断。相似检测是人工审校线索，不是合法性证明。
