# 作品创作约定（可选补充）

供建书或作者明确要求维护作品约定时使用；先读取现有 AGENTS.md，在插件标记块外合并适用条款，不覆盖作者的题材、视角、风格和授权。没有提供的目标读者或开放点保持未知，不补造。此文件不会被当前 book_init 自动写入作品。

## 可合并的规则

- 默认第三人称；对白、明确标示的直接思想和书信可使用人物的第一人称。作者明确指定的其他人称按其适用范围执行。
- 以本书已约定的题材、核心阅读体验与作者风格判断节奏，不强制爽点频率或章末悬念。
- 正文优先呈现人物选择及其后果。已建立的常规工序、例行确认和账目变动，无新增叙事作用时可以概述；保留关键承诺、利益冲突、风险变化及人物反应。
- 创作后台的工具授权、证据与版本核验不自动转化为人物必须遵循的仪式或对白。
- 区分正文事实、角色认知与读者期待。审查同时检查连续性和阅读体验，不为清空记忆台账而强行收尾。
- 采纳按作者已有授权执行；授权要求独立审查时，须审查精确最终版本并解决阻碍问题后才能代采纳。没有此授权则候选等待作者。具体授权范围、撤销或修改保留作者原意，不由模板扩大。

作者明确提供后，可另记本书题材与核心体验、视角、不可改动的结局/场景及有意开放点；这些是作品约束，不是剧情已经发生的证据。
