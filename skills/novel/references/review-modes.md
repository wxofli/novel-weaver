# 单章、章段与完结审查

## 选择尺度

单章审：本场目标、决定、结果是否成立，角色所知是否支持决定，视角与声音是否稳定；指出最值得保留和最值得删改的部分。必要时补读前后文，缺原文不猜。

章段审：用于连续几章、分卷节点或出现重复/停滞反馈时。检查相邻场景功能、升级与局部回报、关系变化、支线占比、信息揭晓顺序；不能由每章均无错推导章段好读。不要求每章后自动进行全书审。

完结审：按[阅读方法](reading.md)核实关键范围，再复盘“开篇承诺→中段升级→最终选择→高潮结果→余波”。检查核心承诺与主要人物的目标、动机、决定、代价和最终处境；单独评最后一幕。若材料不齐，准确给出暂缓或范围有限的判断。

核对主角、主要对手及承担关键转折的配角：终局是否由既定规则、可获得的信息与人物选择推动；巧合解围、临时能力或对手突然失智不能仅凭高潮热闹而略过。重要关系要看到选择如何改变相处或处境。高潮后核对必要后果、解释堆积、连续告别和突然中断；最后一幕/一句须说明留下的感受怎样连接全文情感线，不只评句子漂亮。

## 从读者体验到事实核查

先标记吸引、困惑、跳读或情绪落空的位置，再核对其原因。不要先看台账后逐项要求正文显式证明，否则会把合理省略改成说明书。

关键问题包含位置和短引文、前后关系、对读者的实际影响、最小修法、联动章节及成本（低：句段调整；中：多场删并/移位；高：重构因果或人物弧线）。按阻碍交稿、重要修订、可选打磨排序；“可能更喜欢另一种写法”不算阻碍。

同时回答：本章/段最值得读什么；哪里可能跳读及原因；相比前文新增什么；哪些写法应保留。不要为了凑问题否定已经成立的稿件，也不要把事实正确当作全部质量标准。

## 完结报告

按作者指定格式；没有指定时包含：

1. 判定与两三条决定性理由：可交稿 / 局部修订后可交稿 / 需要结构性返修 / 材料不足，暂缓判定。
2. 实际阅读版本与范围；主线承诺、兑现方式、证据、完成状态。
3. 主要问题及最小修法、成本和联动范围。
4. 应保留的场景、人物选择、结尾写法。
5. 修订优先级与能在新正文中核验的复审标准。

判定按影响而非问题数量：核心因果或最终选择缺口可能需要结构返修；跨多章删重复不必自动判为推翻结构。开放式结局须说明已回答什么、仍允许哪些有依据的解释。多个候选结局分别判定。

## 审查与采纳边界

自审与独立审查分别标明。作者要求另一执行者审查时，交付精确版本、原文及必要上下文，让其独立判断，不预先要求“通过”。修改后须重新审查最终稿。另一执行者不可用时如实说明，不能用自审冒充授权条件已满足。

Review 保存成功仅代表记录有效，不代表质量通过。无阻碍且符合作者授权才可代采纳；审美分歧说明权衡，作者可明确选择保留。未经授权不自动改稿或采纳。

当前 Review 只支持单章 source_version/hash。章段或全书报告在 content 中列全部版本清单和逐条跨章证据，并明确结构化对象仅绑定哪章；structured finding.quote 只引该绑定章的原文。不得把其他章节引文填入该字段，也不得假称后端已支持多章审查。仅阅读无需为记录而强行调用工具。
